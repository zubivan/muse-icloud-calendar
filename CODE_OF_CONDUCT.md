# Code of Conduct

Be respectful. Assume good faith, disagree without personal attacks,
and keep discussion focused on the work.

Harassment, discrimination, and threatening behaviour are not welcome
here, in issues, pull requests, or any other project space.

If you experience or witness behaviour that violates this, report it to
the maintainer through the contact details on the repository's GitHub
page. Reports are treated in confidence.

This is a small project maintained in spare time. Please be patient
with reviews and replies.
