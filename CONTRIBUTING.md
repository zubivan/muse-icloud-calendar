# Contributing to muse-icloud-calendar

We want contributing to be as easy and transparent as possible.

## Pull requests

We actively welcome your pull requests.

1. Fork the repo and create your branch from `main`.
2. If you added code that should be tested, add tests.
3. If you changed behaviour, update the documentation in the same
   change: the Limitations section in `CONNECTOR.md` and the short
   list in `README.md`.
4. Ensure the test suite passes: `python3 -m unittest discover -s tests`
5. Keep the CLI a single file with no third-party dependencies.

## Issues

We use GitHub issues to track public bugs. Please ensure your
description is clear and has sufficient instructions to reproduce the
issue. Never paste a credential, an app-specific password, or a real
`Authorization` header value into an issue, a pull request, or any
other public place.

For security bugs, do not file a public issue. Email the maintainer
instead — see the repository's contact details on GitHub.
