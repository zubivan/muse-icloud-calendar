Connect iCloud Calendar

This page builds the one value Muse's secure form asks for. Nothing you type here leaves this device.

  1. On appleid.apple.com, sign in and open Sign-In and Security → App-Specific Passwords.
  2. Generate a password and name it for this connector, for example “Muse iCloud Calendar”. Apple shows it once, in groups like xxxx-xxxx-xxxx-xxxx.
  3. Type your Apple ID email and that app-specific password below, then tap Build my value.
  4. Copy the result and paste it into Muse's secure form as the key. Then close this page.

Use the app-specific password from step 2, never your real Apple ID password. Spaces are removed automatically.

How to be sure this is safe: the page is one file, it works with the internet switched off, it has no accounts, no analytics and no storage, and its full source is short enough to read. The value it builds is only an encoded form of what you typed — treat it like a password, because anyone who has it can use it until you revoke the app-specific password at appleid.apple.com.
